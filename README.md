# GitHub Pages build

This branch is only the published website: the landing page (from `website/` on the `game` branch) at the root,
and the Godot web export in `game/`. Repository Settings → Pages → Source: **Deploy from a branch**,
Branch: **gh-pages**, folder **/ (root)**.

To update: copy the new `website/` files to the root and the new Godot export to `game/`,
keeping `script.js` pointing at `game/index.html` (not `../game/index.html`).
